# Retail Sales Analytics Dashboard

## Project Overview
Built an interactive retail sales dashboard using MySQL and Power BI to analyze:
- Sales trends
- Regional performance
- Product profitability
- Customer segments
- Discount impact on profit

## Tools Used
- MySQL
- Power BI
- Excel

## Dashboard Features
- KPI Cards
- Monthly Sales Trend
- Regional Analysis
- Top Performing Products
- Profit vs Discount Analysis
- Interactive Filters
